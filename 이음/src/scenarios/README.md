# 이음 발표 시나리오

`npm install` 후 `npm run dev`로 실행합니다.

- `/#/scenarios` : 시나리오 목록
- `/#/scenarios/wallet` : 이음 지갑
- 홈과 기존 시연 제어 화면에도 시나리오 목록 진입 버튼이 있습니다.

추가 시나리오는 폴더별로 데이터와 화면을 분리하고 `registry.ts`에 등록한 다음 `App.tsx`에 경로를 추가합니다. 각 시나리오 상태는 자체 컴포넌트 안에서 관리합니다.

지갑의 지자체 이용 내역과 기관·교육 정보는 발표용 가상 자료이며 실제 연동·결제는 없습니다. 새로고침 또는 ‘이 시연 다시 시작’으로 초기화합니다.
